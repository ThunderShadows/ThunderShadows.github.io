Experience

  • Built an LLM translation service (Python, Flask, OpenAI GPT-4o) that lets credit and operations teams read loan-eligibility rules in plain English. It deduplicates conditions, stores each unique translation so it is paid for only once, batches requests in groups of 20, and validates each JSON response.
  • Integrated a SarvamAI voice agent with Knowlarity telephony over SIP trunks to automate EMI repayment reminder calls for about 20,000 customers. A live server triggers each call and exposes a WebSocket the telephony API listens on; the agent is bridged to the customer and transfers to a human agent on request, with a timed queue delay based on agent availability.
  • Built an admin dashboard backend for managers and dealers to create and manage Agents, Dealers, Showrooms, Vehicles and Vehicle Manufacturers, with site distribution across Karnataka, Maharashtra and Gujarat.
  • Automated SSL/TLS renewal across 3 production domains: a daily cron job checks expiry and renews via certbot certonly within a 7-day threshold.
  • Diagnosed silent loss of WhatsApp delivery callbacks for six days on a lending platform, caused by a reverse proxy caching DNS for a mirrored upstream after a server address change. Fixed it with a zero-downtime reload, and proposed a static/private IP, a duplicate-send guard, and a callback-silence alert so the same failure would be caught quickly.
